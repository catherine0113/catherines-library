# Catherine's Library

A personal reading tracker: shelves for Reading / Want to read / Read, progress, half-star ratings and reviews, notes and quotes by page, a yearly reading challenge, streaks and stats.

- Search books by title, author or ISBN (Google Books + Open Library), with real covers
- Scan the ISBN barcode with your phone camera
- Data stays on your device (IndexedDB). Use **Settings → Download backup** regularly.
- Add it to your phone's home screen to use it like an app.

Barcode scanning uses [ZXing](https://github.com/zxing-js/library) (Apache-2.0) as a fallback where the browser has no built-in barcode detector.
